Variables

Variables make data accessible in a template.

View Markdown

Variables are defined by apps. For example, Obsidian Web Clipper offers Knap variables that standardize content from web pages.

When a template is rendered by Knap, variables are replaced with values. Variables are wrapped in double braces {{ and }}. Whitespace is optional.

Template
Output

Use filters to modify a value. Filters can be chained, and run from left to right.

Setting local variables

Use {% set %} to name a literal, expression, or filtered value for the rest of the template.

Assignments are evaluated in order and can be used by later output and logic. See the set reference for assignment syntax and variable scope.

Nested values

Use dot notation for nested object properties and bracket notation for array items or keys that are easier to express as strings.

Bracket expressions can also use another variable, which is useful when two arrays need to be read in parallel.

Human-readable names

Variable output supports names with spaces, so imported column headings can remain readable without preprocessing.

Value types

Variables can contain strings, numbers, booleans, arrays, objects, and nullish values.

TypeCommon uses
stringTitles, content, URLs
numberCounts and measurements
booleanFeature and state flags
arrayTags, authors, sections
objectNested structured data
nullMissing or empty values
